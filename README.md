# Agents Folder by @kigster

This project is the `~/.agents` folder that contains the `AGENTS.md` file. 

## Goals

The primary goal of this project is to contain a vesioned, portable, set of skills and scripts that I use during the development process. Eventually I would like to create several agents that can work without human intervention on software projects, given sufficent amount of documentation, guardrails, evals, and so on. But this is Phase II. 

### Phase I

This is the initial phase. In this phase we are going to create a general harness for installing the repo,  for symlinking it to `~/.claude`, for creating `~/AGENTS.md` (symlink into the `AGENTS.md` at the root of this project).



At some point I'll add a setup script that will install both of those from this folder.
